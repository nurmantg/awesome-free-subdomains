## 📋 General Subdomain Providers

* **[DEVS.LI](https://devs.li/)** — Free `*.devs.li` subdomains with modern developer dashboard and API.
* **[DigitalPlat](https://domain.digitalplat.org/)** — Free subdomain registration across multiple suffixes.
* **[is-a.dev](https://is-a.dev/)** — Free `*.is-a.dev` subdomains for developers managed via GitHub pull requests.
* **[js.org](https://js.org/)** — Free `*.js.org` subdomains for JavaScript-related open-source projects.
* **[pp.ua](https://nic.ua/)** — Free `*.pp.ua` subdomains with SMS verification.

## ⚡ Dynamic DNS (DDNS) for Homelabs & VPS

* **[DEVS.LI](https://devs.li/for/vps-homelab)** — Fast Anycast A/AAAA record management for Linux VPS and Docker hosts.
* **[DuckDNS](https://www.duckdns.org/)** — Free DDNS service with cron script support.
* **[deSEC](https://desec.io/)** — Free DNS hosting with REST API and DNSSEC support.
* **[Dynu](https://www.dynu.com/)** — Free dynamic DNS service with multiple domain names.
* **[FreeDNS (afraid.org)](https://freedns.afraid.org/)** — Community-driven free DNS hosting.
